#### 3.1 Классы и основные структуры
- [ ] Класс `Player` — игрок
  - [ ] `moveLeft()`, `moveRight()` — переключение дорожек (3 полосы)
  - [ ] `jump()` — прыжок с гравитацией
  - [ ] `update(dt)` — обновление позиции
  - [ ] `getBoundingBox()` — AABB коллизии
- [ ] Класс `Zone` — генерация игровых зон
  - [ ] `static generate(number)` — процедурная генерация
  - [ ] Пол, препятствия, монеты
  - [ ] Цвет = сложность (100м на зону)
- [ ] Класс `Obstacle` — типы препятствий
  - [ ] `barrier` — перепрыгнуть
  - [ ] `wall` — объехать
  - [ ] `moving` — движущееся
- [ ] Класс `Shop` — магазин улучшений
  - [ ] `loadFromStorage()`, `saveToStorage()` — localStorage
  - [ ] `buy(type)` — покупка улучшений
  - [ ] `render()` — отрисовка карточек
- [ ] Класс `Game` — главный контроллер
  - [ ] `init()` — инициализация Three.js сцены
  - [ ] `loop()` — игровой цикл (requestAnimationFrame)
  - [ ] `spawnZone()` — создание новых зон
  - [ ] `checkCollisions()` — проверка столкновений
  - [ ] `onGameOver()` — экран проигрыша
  - [ ] `onStartRun()` — начало забега
